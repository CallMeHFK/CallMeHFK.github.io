SEC.01

$为什么存在

OpenViking 是火山引擎开源的 agent 长期语义记忆引擎。本插件把上游的 Node.js MCP 代理移植为 QwenPaw 原生 Python 插件：7 个工具、5 个技能，没有 Node 运行时，没有任何第三方依赖——记忆检索、写入、技能发现全部走本地进程。

F02
🎓
