SEC.01

$做什么

OpenViking 是火山引擎开源的 agent 长期语义记忆引擎。本插件把上游的 Node.js MCP 代理移植为 QwenPaw 原生 Python 插件，7 个工具、5 个技能，不需要 Node 运行时，也没有第三方依赖。7 个工具都是 OpenViking 服务端 MCP 端点上的薄封装，走 streamable HTTP，会话过期自动重新初始化。工具与钩子一律 fail-open：服务端不可达时只降级成告警。

SEC.04

$要点

F01
🧰

7 个记忆工具

搜索记忆、写入记忆、找技能、读资源……一套 API 覆盖 OpenViking 全功能。

F02
🎓

5 个内置技能

随插件即装的 agent 技能，让记忆读写成为默认动作。

F03
🐍

纯 Python 移植 · 零三方依赖

上游 Node.js MCP 代理 → 原生 Python，进程内直连；没有 Node 运行时、没有 pip 依赖，装了就能用。

F04
🔑

密钥不落盘

OPENVIKING_API_KEY 等凭据全部走环境变量，不写进插件文件；跨域重定向会剥掉 Authorization 与身份头，凭据不跟着跳。

F05
🧠

语义记忆

长期语义索引：agent 的经验跨会话沉淀、按语义召回。

F06
📡

环境代理旁路

tailnet 或 LAN 部署时，环境代理若没把服务端列进 no_proxy，请求会进代理隧道并报出误导性 TLS 错误。插件对配置的主机默认绕开环境代理（proxy_bypass 可关），启动体检会做反向探测并在日志说明哪条路可用。

SEC.05

$路线与限制

  • 限制

    需要一个可达的 OpenViking 服务端，默认地址 http://127.0.0.1:1933。服务端不可达时工具与钩子 fail-open，只降级成告警。

  • 限制

    7 个工具安装后默认 disabled，要在 QwenPaw 工具设置里逐个启用。宿主版本窗口为 QwenPaw 1.1.6 到 2.3.0 之前。
