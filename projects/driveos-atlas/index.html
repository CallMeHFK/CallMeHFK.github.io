SEC.01

$为什么存在

车载 SDK 的文档是那种「搜得到但走不动」的东西：一千多篇 Markdown，章节之间互相引用，可你从一篇跳到另一篇只能靠侧边栏一层层点。driveos-atlas 把整份镜像编译成一张图——节点是文档，边是引用——让你在三维里看清哪一片是核心概念、哪一片是平台定制、谁被引用得最多，然后点进去用抽屉读正文。

它是纯静态的：没有后端，没有服务进程。tools/build.mjs 在构建期就把布局算好、把倒排索引建好、把正文切成懒加载的桶，运行时浏览器只拿 graph.json + search.json + 按需的一个正文桶。这也意味着它可以整份挂到任何静态托管上，或者就在 127.0.0.1 上开着看。

SEC.02

$能力清单

F01
🧊

三维 / 平面双视图

src/solid.js 是 three.js r186 的 WebGL 渲染器，src/flat.js 是 canvas 2D 回落。src/app.js 负责在两者之间切换：拿不到 WebGL 就自动落到平面视图，并明说一句「此浏览器无 WebGL，已回落平面视图」——不静默降级。选择记在 localStorage 里。

F02
🏷️

主题簇着色

按章节目录分簇上色（CHAPTER_LABELS），所以「核心概念」和「生产部署」在图里是两团不同颜色，不是一锅均质毛线。

F03
🔍

倒排索引即时检索

search.json 是构建期生成的倒排索引，检索在浏览器本地完成，不发请求、不等后端。另有章节级全文检索。

F04
🔗

hash 深链

URL 里的 #/doc/<id> 直接落到某一篇并打开抽屉，所以图上任何一个位置都能被复制、被贴进 issue、被bookmark 回来。

F05
📖

抽屉式正文阅读

正文在右侧抽屉里读，抽屉宽度可拖（记在 atlas.drawerw），开关同步 aria-hidden。中文模式下大纲另有一套处理——翻译后的标题不一定保得住原文的 slug。

F06
🌐

BYOK 中文翻译

src/i18n.js 按需机翻正文，走你自己填的 OpenAI 兼容端点。密钥与译文都只活在这个浏览器里，发布产物两样都不带。系统提示要求严格保持 HTML 标签与属性、代码、命令行、文件路径、API / 变量 / 宏等标识符、版本号与单位原样不变，只翻译标签之间的自然语言句子。正文按 6000 字符分块，译文缓存在 localStorage，预算 4,000,000 字符——因为 localStorage 总共约 5 MB，得给应用本体留地方。

F07
🪣

正文按桶懒加载

构建期把正文切成 web/data/docs/<chapter>__NNN.json 一批桶，graph.json 里每个文档只带一个桶序号 p，另存 buckets 与 bucketBytes 两张表。读一篇只解一个桶，不把整份语料拖进内存。

F08
📐

布局在构建期算完

tools/build.mjs 里用空间网格分桶找邻居（grid.get(gx+dx, gy+dy, gz+dz)）来算布局，运行时不再迭代。所以打开就是最终形态，不会看它在眼前慢慢弹。

F09
🛠️

四个构建脚本，没有框架

build.mjs（图谱 + 索引 + 正文桶）、bundle.mjs（esbuild 打 src/ → web/app.js 并拷 index.html / styles.css）、md.mjs（Markdown 处理）、serve.mjs（本地回环预览）。开发依赖只有两个：esbuild 与 three。

SEC.05

$路线

  • 已落地

    三维 / 平面双视图、主题簇着色、倒排索引即时检索、章节全文检索、hash 深链、抽屉式正文阅读（含 BYOK 中文翻译）——README 列的六项能力，逐个在 src/ 里能找到实现：solid.js / flat.js / app.js 的 #/doc/ 分支 / i18n.js

  • 已落地

    构建产物按「读一篇只解一个桶」切分，并把桶名与桶字节数写进 graph.json；HEAD 提交（275d77b）做的正是让外壳的语料计数取自构建报告，而不是另算一遍

  • 边界

    文档镜像不在仓库内（版权原因，.gitignore 逐个列出 /core-concepts/、/platform-customization/ 等章节目录）。所以这个仓库无法开箱复现：没有镜像就没有输入，npm run make 无从产出 web/。代码本身 MIT，文档内容版权归 NVIDIA

  • 边界

    README 说的「1627 篇」只是文档断言：镜像不在仓库，这个数字在任何源文件里都找不到（grep -rn 1627 无命中），build.mjs 是运行时算 docs.length 的。本页照录不背书

  • 边界

    没有测试，也没有 CI——收例数 0，工作流目录不存在。仓库没有 LICENSE 文件，MIT 只在 README 的「许可」一节声明。package.json 写着 1.0.0 且 private: true，从未打 tag 或发 release

  • 边界

    README 里那个线上实例（driveos-atlas-8nsdsfrx9xv.qoder.zone）在本页写作时连不上：域名能解析，但 TLS 握手以 unexpected eof while reading 失败。所以本页不放「在线演示」按钮——不放一个自己没验过能打开的链接

  • 边界

    BYOK 翻译是按需机翻，质量取决于你填的端点；密钥与译文只在本机 localStorage，清站点数据即失效。默认打开 noThink，因为默认开推理的模型家族做翻译需要把它关掉

仓库没有 Roadmap 一节，issue 区从建库至今是 0 条（open 与 closed 都为 0），所以这里没有「计划」行——只有已落地与边界。同一个问题形状的第二代解法是 site-kg：把「一个特定 SDK 的镜像」换成「任意站点 URL 或本地目录」，并加一层 MCP 接口给 agent 用；两者都用 three.js r186。
