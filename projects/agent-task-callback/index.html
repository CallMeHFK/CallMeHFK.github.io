SEC.01

$为什么存在

submit_to_agent 返回 task_id 之后就没有然后了：结果躺在子任务记录里，直到某个 agent 想起来去 check_agent_task。这个插件为每个任务注册一个 watcher，当任务到达终态时，把结果作为新的一轮回投到注册它的会话——父 agent 不用轮询也能把线索捡回来。
