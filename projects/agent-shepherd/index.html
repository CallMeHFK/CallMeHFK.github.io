SEC.01

$为什么存在

agent-shepherd 监督 QwenPaw / Claude Code / Codex 的推理与工具执行。Tier 0 是零成本确定性探测器——不调用模型、从不猜测；Tier 1 是可选的 LLM 步骤打分器，只在 Tier 0 看到证据时才醒来，让昂贵的评审在 agent 健康时保持沉睡。判定通过一道由观测结果拟合的风险门，而非裁判自报的置信度。

SEC.02

$能力清单

F01
⚡

Tier-0 确定性探测器

每个事件都跑，零模型成本；规则命中才算数，绝不猜。规则本条目按 Wilson 下界排序，几个样本的案例压不过久经检验的条目。

F02
🧠

Tier-1 打分与风险门

为最近步骤评 on-goal / justified / verified；只在 Tier 0 有证据时唤醒。判定准入由观测到的结果拟合，不采信裁判自报的置信度。

F03
👁️

三宿主适配

QwenPaw · Claude Code · Codex 一套钩子全部覆盖。重装时先摘掉旧形状的 shepherd 条目再写当前形状，不会让同一个事件触发两次钩子。

F04
📒

可审计账本

看到的一切都追加进 ledger，支持离线 replay。

F05
📏

反事实基准

「它值这个成本吗」是一条可以运行的命令，不是 README 里的口号。

F06
🧯

监督者不许变成事故

并发 ingest 下按会话串行化状态；风险分写失败只丢这一次评分，不会把会话卡死；QwenPaw 插件的钩子全改成 async，不再以超时阻塞 agent 的事件循环；本机裁判流量默认绕开代理环境变量。
