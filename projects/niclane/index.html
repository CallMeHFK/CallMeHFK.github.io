SEC.01

$为什么存在

现代笔记本很少只有「一个网络」：WiFi 在办公网，USB 坞是第二条上行，VPN 的 TUN 设备、Tailscale、Docker 网桥共存于同一张路由表，还常被全局 TUN 代理劫持。niclane 把每张网卡变成独立车道：一个出口硬绑定到指定网卡的本地代理监听器。车道之间互不可见、不共享路由、绝不串线。接口掉线时立即拒绝新连接——绝不静默改道。

SEC.02

$能力清单

F01
📌

出口硬绑定

Linux 用 SO_BINDTODEVICE，macOS 用 IP_BOUND_IF，把 socket 钉死在一张网卡上。

F02
🚧

Fail-closed

监视器每 2 秒复查接口；不健康且 strict 时，拨号直接拒——没有兜底，没有泄漏。

F03
🔎

车道内 DNS

域名解析经本车道拨出，支持 DoH（AliDNS / Cloudflare），DNS 不外泄。

F04
⛓️

上游代理链

可链 socks5:// 或 http:// 上游——上游连接本身也走本车道。

F05
📊

全量计数

连接数、拒绝数、双向字节、DNS 查询、UDP 报文，Prometheus 格式导出。

F06
📦

UDP ASSOCIATE

RFC 1928 UDP 中继经车道绑定的 UDP socket 转发。
