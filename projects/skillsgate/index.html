SEC.01

$为什么存在

不用再翻 GitHub 仓库、手抄 markdown 文件了。SkillsGate 在一个界面里浏览、搜索、安装 AI agent 技能——集成 skills.sh 公共目录，一键装到任意组合的 agent。桌面应用覆盖 macOS / Windows / Linux，设置与收藏全部存在本地 SQLite，无需账号。
